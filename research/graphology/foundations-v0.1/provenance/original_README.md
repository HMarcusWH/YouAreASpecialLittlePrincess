# Graphology foundations — research draft 0.1

Read `graphology_foundations.md`, then `question_catalogue.md`.

- `sources.json` records the source basis, exact access depth and limitations.
- `graphology_question_selector_blueprint.json` contains the proposed source-aware data model and draft question/selector catalogue.
- `validation_report.json` records structural checks actually run on this draft.

The package contains 89 proposed question/selector definitions, 44 fixed value sets (156 value entries), 33 dynamic candidate kinds and eight soft-text fields. These are application-authored operational proposals anchored to source domains, not copied official exam questions or a claim of a complete historical dictionary.

All questions remain DRAFT. The two historical association examples are research-only. A source mention is not a numerical rubric or empirical validation. The merged repository's UNPOPULATED production scaffold is unchanged.

No images, private participant data, copyrighted source reproductions, model calls or production credentials are included.
