# Graphology question and selector design catalogue

**Status: research draft, not an activated report pack.** Question wording, operational bands, and routing are application proposals. Source links establish the underlying domain or term only unless an assertion explicitly says otherwise.

This draft contains 89 question/selector definitions, 44 fixed value sets, 33 dynamic candidate kinds and 8 bounded text fields.

Read `graphology_foundations.md` for the school and evidence model. `sources.json` records access depth and limitations.

Answer states are separate from observed values. Unknown is not a low score. An observed mixture carries regional evidence; it is not a fallback for uncertainty.
