# Presentation content v1

This directory is the reviewed source for T08A mechanical presentation content.

- `presentation.json` owns English/Swedish Free feature labels, intrinsic/predeclared non-population display domains, and deterministic first-reveal candidate rules.
- `tools/generate_presentation_content.py` validates the source and copies the exact reviewed registry to the backend package and product-contract handoff.
- Candidate witnesses are synthetic rule-reachability controls, not claims about real writers or population frequency.
- Candidate thresholds are frozen product-presentation bands, not estimates of population frequency. Candidate strength is normalized within those reviewed bands where practical and is an internal deterministic selection signal only; it is never a percentile, rarity score, confidence value, or user-visible ranking.
- Ink/stroke wording is explicitly qualified as an image property and never presented as physical pen pressure. The ink family may appear as supporting/secondary context but is excluded from the primary hero because it is especially capture-sensitive.
- Spacing highlights require at least three accepted gap observations. Population-relative mappings, calibrated normalization, rarity and population-rank claims remain T06/T08/T13 work.

Do not add client-side salience selection. Clients render the server-selected content/support IDs or the explicit no-eligible fallback.
