# Web release evidence checklist

[Index](../roadmap/00-index.md) · [Web implementation](../roadmap/10-web-client-and-api-integration.md) · [Gate matrix](../roadmap/21-release-readiness-checklists.md) · [Final signoff](multi-platform-signoff.md).

Status: PENDING. This is a required evidence template, not a completed release record. T17/T20/T21/T22 own implementation; T23 verifies journeys; T24 operates deployment; T25 approves public release.

- [ ] Record candidate commit, deployed artifact digests, API/schema/engine/report/model/reference versions and exact test run links.
- [ ] Demonstrate upload/crop/suitability/partial Free report with real authorized supported captures and synthetic edge fixtures.
- [ ] Verify desktop/mobile browsers, keyboard/screen-reader/reduced-motion behavior, Swedish/English labels and chart text alternatives.
- [ ] Verify secure session/CSRF/CORS/cache boundaries, guest migration, logout/account switching and cross-owner denial.
- [ ] Demonstrate confirmed web purchase, pending/failure/refund, duplicate-event recovery, Premium refusal/failure and saved-result reopening without a model call.
- [ ] Show deterministic pair/history comparison, partner permission, redacted share preview/revocation and evidence-preserving PDF/card parity.
- [ ] Verify contribution refusal/withdrawal, account/data deletion, late jobs, expired asset tickets and backup tombstone behavior.
- [ ] Confirm provider-disabled Free, resource quotas, cost breakers, safe telemetry, support/refund/deletion contacts and incident runbooks.
- [ ] Review landing/paywall/metadata claims against enabled capabilities; no unsupported rarity, active-traditional or personality-validity promises.
- [ ] Record hosting/domain/TLS, processor/region/retention approvals, rollback/canary plan and named release approver.

For each checked item attach actual evidence and reviewer/date in the candidate release record. A screenshot alone does not prove authorization, payment or numerical correctness. An earlier private web alpha does not satisfy the native programme gates.
