## Release conditions

All hard task predecessors and required human gates must have actual evidence. Advertised features must match enabled capabilities on every supported client. Native purchases use approved platform paths; credit/report recovery is account-backed and tested. Free works with Premium disabled. No reference/traditional claim activates without its separate evidence. Production secrets/real customer data remain outside the repository.

Complete the three platform checklists and the full core journey under degraded/failure states. If a capability is intentionally removed from marketed scope, record an explicit scope amendment and dependency/gate review; do not silently mark an unmet task DONE. A partial web launch must be named a separate slice rather than declared full multi-platform completion.

Store acceptance, deployment and public release each require a recorded decision. T25 authorizes the staged publication of approved artifact digests only. Monitor and halt according to the tested runbooks; do not bypass a store rejection or privacy/billing failure through an alternate distribution path without a new approved plan.
