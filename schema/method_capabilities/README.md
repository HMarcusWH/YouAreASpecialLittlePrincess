# Method capability authority

`v1/methods.json` is the reviewed declaration source for execution capabilities. `resolved.json` is generated by T01 and is the executable authority consumed by product code.

A method declares the canonical features it can emit, input mode, runtime component, learned/provider requirements and method dependencies. The compiler validates those feature mappings against the canonical 272-feature database and resolves the full dependency closure before deciding whether a method is Free-eligible.

**Free is a computed property, not a label.** A method is Free-eligible only when its entire transitive dependency closure has no learned inference, external provider, or non-Free runtime component. The existing feature database's `free_compute` field is descriptive metadata and cannot override this graph.

The current deterministic engine surface resolves to 21 Free classical methods and 64 emitted canonical features. `sigver_representation_v1` is explicitly learned/non-Free even though the historical `SIG_EMBEDDING` feature metadata has `free_compute: true`.

T01 tests execute the real Free engine with socket construction/connection denied and verify that its emitted method/feature surface equals the resolved manifest. T28 may give the Free worker stronger process/container egress isolation, but it must preserve this same capability decision.
