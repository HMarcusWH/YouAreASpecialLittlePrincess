# Authoritative product construction

`runtime.compile_document()` creates immutable validated product values; generated declarations alone are not validation. Cross-document projection and Premium-output checks preserve current authority and support confinement.

Edit the reviewed source in [contracts/product/v1](../../contracts/product/v1/README.md), then follow [generation](../../docs/reference/generated-assets.md). Numerical definitions, interpretation source and policy/permission authority remain separate inputs. No contract generator activates a provider, a traditional association or a public reference claim.
